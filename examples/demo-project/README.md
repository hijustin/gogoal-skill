# GoGoal 演示项目

此目录包含一组可直接校验和查看的演示数据，不依赖仓库根目录的开发参考文件。

```bash
python3.12 ../../skills/gogoal/scripts/gogoal.py validate
python3.12 ../../skills/gogoal/scripts/gogoal.py summary
python3.12 ../../skills/gogoal/scripts/gogoal.py dashboard serve --open
```

演示目标包含已完成与执行中的 AI 任务，以及等待用户确认的用户任务，便于观察关联筛选、状态列、浮框、时间线和 Markdown 阅读。
